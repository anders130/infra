# rackflix

QNAP NAS hosting media, documents, and backups.

## Warning

> [!CAUTION]
> This host is **not managed by NixOS**. Configuration must be done manually through the QNAP admin interface.

## Services

| Service   | URL                       |
| --------- | ------------------------- |
| Admin     | http://admin.rackflix     |
| Paperless | http://paperless.rackflix |
| Plex      | http://plex.rackflix      |
